# 通知、计分板与任务分类交互

本轮基于 Kotlin、Jetpack Compose、Miuix 0.9.4，实现位于现有 App 中，不增加依赖、不更换导航、计分或通知业务逻辑。

## 布局与动画

- `OverlaySheet` 继续使用官方 `OverlayBottomSheet`，由其统一管理滑入、滑出、拖动和遮罩；不叠加第二份遮罩或窗口动画。通知和计分板保持相同表面与间距节奏；移除显式关闭按钮，保留系统返回、下滑和外部点击关闭。
- 计分板保持固定、有界的内容视口；榜单、明细、规则切换使用 200 ms 淡入淡出与轻微位移。动画持有各视图的数据快照，通过视图标识识别目标，避免退出视图读到新视图的数据。
- 关闭计分板时先完成官方退出动画，再通过 `onDismissFinished` 清理当前明细/规则选择。关闭被重新打开打断时，依赖官方取消语义，不提前清空内容。
- 通知内容展开仅改变一个文本节点的行数，通过 200 ms 尺寸动画过渡；分类设置展开/收起采用 180 ms 的淡入和高度动画。
- `SegmentedTabs` 通过实际 Compose 文本 intrinsic 测量获得每项宽度，包含真实字体、缩放和内边距；空间不足时先保留触控空间，再按需求分配剩余像素，分类名和计数分别测量、保持单行，极窄空间省略溢出，避免数字单独换行。
- 分类器外部区域占满可用宽度，内部轨道按内容测量，由 `Alignment.Center` 居中。选中背景使用同一个 `Animatable<Rect>` 同步过渡位置与宽度，时长 240 ms，使用 `FastOutSlowInEasing`。首帧使用实际放置坐标，不从零宽度或第一项飞入；新点击取消旧目标，从当前矩形继续。
- 文字颜色与分类切换使用相同缓动。位置取实际放置结果，支持 RTL；长短标签与任务计数不依赖字符数量估算或逐项偏移修正。
- 次级按钮复用 Miuix `Button`/`IconButton`，使用主题色、48 dp 最小触控区、轻量按压反馈和状态语义；按压只影响内容透明度，不缩小点击区域。
- 社区“我的帖子”保留原有筛选与返回流程，加载期间避免重复切换。聊天免打扰保留直接切换语义，异步保存期间禁用操作，新状态仅在真实成功响应后显示。
- 自定义动画读取现有 `LocalEffects.reduceMotion`，关闭时长；弹层沿用 Compose/Miuix 的系统动画缩放处理，不自建计时器。

.\gradlew.bat :app:compileDebugKotlin :app:testDebugUnitTest --console=plain
.\gradlew.bat :app:compileDebugR8Kotlin :app:lintDebug :app:testDebugUnitTest --console=plain

## 截图复查后的调整

- 通知列表首屏只保留紧凑状态、筛选和正文；搜索默认收起，推送开关移到标题栏的通知设置入口，使用同一弹层内的有界转场。
- 消费已有通知 metadata 的人员、积分、执行期限、执行状态与检讨正文；预览展示两条真实明细，可展开全部。历史公示正文重复的人员和期限不叠加显示；按复查要求，卡片仅保留一个明细展开入口，普通通知同一入口展开完整正文。未知或不完整 metadata 自动回退原文，不臆造零分。
- 新增 5 项解析与回退测试，覆盖三种合并公示、完整正文、服务端排序、未知/部分元数据、缺失积分和空段落预览。
- 任务计数独立于分类名称，减少分类器重复横向留白；填写入口与截止时间放在同一操作行，正文使用完整可用宽度。
- `assembleProduction`、`testDebugUnitTest`、`lintDebug` 和对应源码归档生成通过。友盟 common 的既有 stack-map 警告仍存在，本次没有屏蔽它。

## 第二轮复查

- 通知不再显示关闭图标；搜索、刷新、设置统一在同一行、48 dp 触控区与 22 dp 图标尺寸。全部已读持续显示，无未读时禁用，沿用现有已加载记录的批量标记逻辑。
- 卡片操作仅保留带底色的展开/收起明细与标为已读；已读记录显示禁用的已读状态。移除重复的查看原文入口。
- 计分板取消单独的规则/刷新大按钮行，改为标题栏同高图标。周次以周起止日期展示，不再重复解释时区；个人周积分单独成卡，分数字号减小，三项来源与排名列表分离。权限、排序、周切换和人工登记逻辑保持原样。
- 任务填写恢复 Miuix 主色底与白字，保留与截止时间同一行的布局。

## 通知与聊天的后续修复

- 全部已读移出搜索、刷新、设置图标行，放入筛选下方的列表操作区，保留低饱和底色和 48 dp 触控区域。无未读时禁用，沿用已加载记录的批量标记与版本校验。
- 明细展开与收起使用同一个 `AnimatedContent`，以 200 ms 淡入淡出和 `SizeTransform` 保留离场内容直至收缩完成；移除外层重复尺寸动画，避免 LazyColumn 内删除内容导致收起突变。减少动画时为 0 ms。
- 聊天会话的免打扰移至右上角，只有开/关两个图标状态；保存期间禁用重复点击，等服务端成功后更新图标及本机过滤状态，失败继续显示原状态。
- 推送设置增加友盟/FCM 注册状态；客户端不显示 token 或原始 SDK 错误。通用注册失败可重试，FCM 检查节流。友盟 FCM 适配器仍使用旧 token 协议，因此此处保留兼容 API，不切换 Firebase 的 FID 注册协议。
