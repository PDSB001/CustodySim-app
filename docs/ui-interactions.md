# 通知、计分板与任务分类交互

核对日期：2026-11-01。基于 Kotlin + Jetpack Compose + Miuix 0.9.4，实现位于现有 App 中，不新增依赖、不更换导航或业务逻辑。

## 通用约定

- 弹层统一用官方 `OverlayBottomSheet`（本仓库封装为 `OverlaySheet`），由它管理滑入、滑出、拖动与遮罩；不叠加第二份遮罩或窗口动画，也不再放显式关闭按钮——系统返回、下滑、点击外部关闭。
- 触控区不小于 48 dp；按压反馈只改内容透明度，不缩小点击区域。
- 自定义动画读取 `LocalEffects.reduceMotion`：开启时把时长降为 0；弹层本身沿用 Compose/Miuix 的系统动画缩放处理，不自建计时器。
- 文案不写死分值、人数或时间：这些必须来自接口响应或用户输入。

## 用户协议与隐私政策（离线弹层）

- 入口：登录页底部的「用户协议与隐私政策」，以及「我的 → 用户协议与隐私政策」；两处打开同一个 `LegalDocumentsSheet`。
- 正文来自 `app/src/main/assets/legal/{privacy,terms}.json`，随安装包分发：**不需要浏览器、登录、服务器连接或任何设备权限**。
- 顶部协议切换与任务分类、通知筛选共用同一个 `SegmentedTabs`：按真实文字宽度测量、滑块 240 ms 补间、减少动效时直接落位，并带 `Role.Tab` 与 selected 语义；不再自绘两个按钮。
- 弹层不提供关闭按钮，关闭依赖系统返回、下滑与点击外部（`OverlaySheet` 统一行为），标题栏只保留标题。
- 正文顶部显示“版本 + 更新及生效日期”，正文区域可长按选择复制，标题块带 `heading` 语义便于读屏跳转。
- 读取失败显示错误与「重新读取」，不静默显示空页；读取过程停留在“正在读取协议…”。
- 阅读协议**不会**记录同意、不会开启通知或定位；注册与同意只在 Web 端发生。协议更新需要同步资源并重新打包，服务器部署无法替换旧安装包里的文本。

## 通知弹层

- 首屏只有紧凑状态、筛选与正文；搜索默认收起，推送开关移入标题栏的通知设置入口。
- 「全部已读」在筛选下方的列表操作区，带低饱和底色与 48 dp 触控区；无未读时禁用。批量提交携带通知版本，服务端已更新时要求刷新后再提交。
- 明细展开/收起使用同一个 `AnimatedContent`（200 ms 淡入淡出 + `SizeTransform`），保留离场内容直到收缩完成，避免 LazyColumn 内删除内容造成收起突变；减少动效时为 0 ms。
- 卡片只保留“展开/收起明细”和“标为已读”两个操作，已读记录显示禁用的已读态；普通通知用同一入口展开完整正文。
- 消费已有通知 `metadata`：人员、积分、执行期限、执行状态与检讨正文，预览展示两条真实明细。历史公示里重复的人员与期限不叠加显示；未知或不完整的 metadata 回退原文，不臆造零分。

## 考核计分板

- 固定、有界的内容视口；榜单、明细、规则三个视图切换用 200 ms 淡入淡出与轻微位移。动画持有各视图的数据快照，靠视图标识识别目标，避免退出视图读到新视图的数据。
- 关闭时先走官方退出动画，再由 `onDismissFinished` 清理明细/规则选择；关闭被重新打开打断时依赖官方取消语义，不提前清空。
- 标题栏放同高的规则与刷新图标，不单独占一行；周次以周起止日期展示，不重复解释时区；个人周积分单独成卡，三项来源与排名列表分离。
- 分项数值、排名与规则说明都来自 `/api/scores` 的 `policy` 与明细权限，客户端不改写、不补零。

## 任务分类与分段控件

- `SegmentedTabs` 用实际 Compose 文本 intrinsic 测量每项宽度（含真实字体、缩放、内边距）；空间不足时先保留触控空间，再分配剩余像素；分类名与计数分别测量并保持单行，极窄时省略溢出，避免数字单独换行。
- 引导轨道外部区域占满宽度，内部轨道按内容测量并由 `Alignment.Center` 居中；选中背景用同一个 `Animatable<Rect>` 同步位置与宽度，时长 240 ms，`FastOutSlowInEasing`。
- 首帧使用实际放置坐标，不从零宽度或第一项飞入；新点击取消旧目标并从当前矩形继续。支持 RTL。
- 任务计数独立于分类名，减少重复横向留白；填写入口与截止时间放在同一操作行，正文使用完整可用宽度。

## 社区、聊天与设置项

- 社区“我的帖子”保留原有筛选与返回流程，加载期间避免重复切换。
- 聊天免打扰位于右上角，只有开/关两个图标状态；保存期间禁用重复点击，服务端成功后才更新图标与本地过滤状态，失败继续显示原状态。
- 推送设置展示友盟/FCM 注册状态；不显示 token 或原始 SDK 错误，通用注册失败可重试，FCM 检查有节流。
